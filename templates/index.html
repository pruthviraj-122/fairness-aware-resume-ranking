Architectural Model Comparison

Scientific comparison of candidate ranking models and trade-offs between pure relevance and algorithmic equity.

Ranking Architecture Feature Foundations Computational Cost Demographic Parity Utility Retention
TF-IDF Lexical Baseline Sublinear token frequencies, n-grams (1,2), domain stopwords < 5 ms (Low) Unconstrained 100.0% (Pure Lexical)
Semantic Transformer Baseline Dense embedding cosine similarity (all-MiniLM-L6-v2) ~50 ms (Medium) Unconstrained 100.0% (Pure Semantic)
Hybrid Multi-Aspect Model Skills (40%) + Semantic (30%) + Experience (15%) + Education (15%) ~15 ms (Low-Medium) Unconstrained 100.0% (Multi-Aspect)
Fair Reranked Hybrid (FA*IR) Hybrid scores + Bounded-regret demographic quota allocation ~20 ms (Low-Medium) Bounded by Pool Proportions ≥ 95.0% DCG Retention

Empirical Research Findings & Trade-offs

Experimental results across benchmark datasets indicate that pure lexical TF-IDF approaches are susceptible to keyword stuffing, whereas hybrid scoring provides more balanced candidate evaluation. Post-processing reranking via FA*IR achieves demographic parity with minimal Discounted Cumulative Gain (DCG) utility loss (>99% retention on benchmark cohorts).
